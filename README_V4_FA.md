# املاک ملکی V4
نسخه V4 شامل:
1. PostgreSQL واقعی
2. JWT + bcrypt
3. ثبت‌نام و ورود
4. ثبت آگهی با وضعیت pending
5. تایید/رد توسط مدیر
6. پنل ساده مدیریت
7. آپلود تصویر
8. جستجوی PostgreSQL
9. کلاینت Godot از نسخه V3

## اجرا
Docker Compose نصب باشد:
docker compose up

سپس API روی پورت 3000 است.

هشدار امنیتی: مقدارهای CHANGE_ME را قبل از انتشار عوض کنید و در محیط عمومی HTTPS و Secret Manager استفاده کنید.

## APK
فایل Godot برای ساخت APK آماده است، ولی این بسته ادعا نمی‌کند APK نهایی روی دستگاه واقعی تست شده است؛ ساخت APK به Android SDK/Gradle نیاز دارد.
