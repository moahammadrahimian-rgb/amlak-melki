# SEO Web

برای سئو واقعی، نسخه وب باید SSR/SSG داشته باشد (مثلاً Next.js) و صفحات قابل ایندکس تولید کند:

/ 
/buy
/rent
/sell
/properties/[id]
/city/[city]
/category/[category]

هر صفحه باید title، description، canonical، OpenGraph، JSON-LD، sitemap.xml و robots.txt داشته باشد.
Godot برای اپ اندروید استفاده می‌شود؛ SEO اصلی باید در وب انجام شود.
